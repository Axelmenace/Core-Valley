# 09 Glossary

**Contains:** every framework term in one line, alphabetical, with the file that defines it.

**Read when:** a term's exact meaning matters, or before writing framework prose, so that terms stay fixed.

---

| Term | Meaning | Where |
|---|---|---|
| **Actual question** | A question about what *is*; verdict Determined, Elected or Open | 04 §4.3.1 |
| **Adjacency** | Two Domains are adjacent iff their units interact; Contact or Channel | 01 §1.9 |
| **Admitted / Distributed / Prohibited** | The three verdicts a modal question can receive | 04 §4.3.1 |
| **Arity Rule** | Every Generation Edge has at least two senders | 03 §3.3 |
| **Asymmetry Gradient** | A Domain's ordering of its Channels by capacity, per direction | 01 §1.10 |
| **Axiom Force** | Strict, Default or Tendency; decides conflict typing | 06 F1 |
| **Base setting** | The period or genre template a setting starts from; the Substrate's Base layer | 01 §1.4, 08 §8.2 |
| **Buy-in** | Attention-capital a narrative work accrues; sets the exposition budget | 08 §8.3 |
| **Certification Ladder** | C0 Mapped, C1 Exercised, C2 Co-resident, C3 Adjacent, C4 Saturated | 06 V7 |
| **Channel** | Persistent adjacency; the only adjacency that carries Configuration | 01 §1.9 |
| **Closure / Closure Test** | The System decides every modal question in its scope | 04 §4.3 |
| **Closure Register** | The recorded modal and actual questions and their verdicts | 04 §4.3.2 |
| **Closure Scope** | Declared System Boundaries plus every question committed content raises | 04 §4.3.2 |
| **Codex-borne** | A medium that hands the reader System directly; the Deductive regime | 08 |
| **Conceit** | Any element of a setting at any tier; a Node of the graph | 01 §1.6 |
| **Configuration** | A Domain's possibility space as the capacity-weighted product of adjacent Realized States | 01 §1.11 |
| **Constraint Principle** | The one gate: can this candidate exist within its Domain's configuration? | 02 §2.1 |
| **Contact** | Temporary adjacency; qualifies adjacency, carries no configurational weight | 01 §1.9 |
| **Contentialist** | A content-first worldbuilder; works by Inference | SKILL.md |
| **Couplings** | Where one System changes another's numbers; recorded when a setting runs several Systems | 04 §4.2 |
| **Coverage Rule** | Every Generation Edge is licensed by a named governing System | 03 §3.3 |
| **Critical load** | The Conceits that lose every license when an axiom is struck | 03 §3.5 |
| **Cycle Licensing** | Stability needs a balancing loop; growth a reinforcing loop; recurrence a delayed loop or a forcing System | 04 §4.7.2 |
| **Debt Register** | Ad hoc patches admitted provisionally, awaiting promotion or replacement | 06 V3 |
| **Decomposition Rule** | An apparent generation that resists Arity or Coverage decomposes through intermediate Conceits | 03 §3.3 |
| **Determined / Elected** | The two strengths of a license: forced by System over Substrate, or chosen | 01 §1.3.1 |
| **Determination Ratio** | Determined Lore over Determined plus Elected Lore | 01 §1.3.1 |
| **Discovery** | Expansion of the epistemic possibility space of a Domain | 02 §2.2 |
| **Discretion Table** | The decision function that closes an in-world will | 04 §4.3.4 |
| **Domain** | A nested region of a Field, containing units | 01 §1.8 |
| **Domain Coherence Criterion** | A Domain is well formed iff its persistent-interaction graph is connected | 01 §1.8 |
| **Dominance Rule** | Analysis resides at the highest tier a Conceit's components reach on any dimension | 01 §1.2.2 |
| **Election** | An authorial choice among licensed runs; recorded, then joins the Substrate | 01 §1.3.1 |
| **Emergence** | Formation of a new unit from a Persistent Relation; the sole minter of Edges | 02 §2.4 |
| **Entailment** | Determined licensure; Revision 04's name for the whole tier relation | 01 §1.3.1 |
| **Expression Rule** | Every license bears both the Licensing and the Inferential reading | 01 §1.3.2 |
| **Fecundity Criterion** | A patch must license new Lore beyond what closing the conflict needed | 06 V3 |
| **Field** | A stratum of emergence: Metaphysics, Physics, Biology, Ecology, Mind, Culture, Technology, Economy, Polity | 01 §1.7 |
| **Generation Edge** | Directed from a sender set to a receiver; minted only at the Persistence gate | 03 §3.2 |
| **Genesis classes** | Stipulated, Designed, Emergent | 02 §2.6 |
| **Grounding** | Support by fixed point from Stipulations | 03 §3.5 |
| **Inference** | Bottom-up reading: abducing structure from instances | 01 §1.3.2 |
| **Inferential regime** | Transmission through narrative-borne media | 08 §8.3 |
| **Island** | A connected component of the graph; one with no System is a Lore–System inversion | 03 §3.5 |
| **Lens** | Stance of content held by a population or agent inside the setting | 01 §1.5 |
| **License link** | The tier-axis link; Determined or Elected | 03 §3.2 |
| **Licensed Space** | The runs a System over a Substrate admits | 01 §1.3 |
| **Licensing** | Top-down reading: deriving Lore and Narrative from System | 01 §1.3.2 |
| **Loop** | A cycle of persistent Channels, balancing or reinforcing | 04 §4.7.1 |
| **Modal question** | A question about what *can* be; must be decided within the Closure Scope | 04 §4.3.1 |
| **Modal Test** | Tier by modal force: substrate-general (System), realized pattern (Lore), singular (Narrative) | 01 §1.2.1 |
| **Optimizer Test** | Stated Lore must be an equilibrium of competent in-world agents using the System | 04 §4.7.3 |
| **Orphan** | A Node of degree zero over licenses and Edges | 03 §3.5 |
| **Patch cost order** | Explication, scope or priority, substrate or context, parameter, new System | 06 V2 |
| **Persistence gate** | The boundary between diegesis and construction | 02 §2.4, 03 §3.4 |
| **Persistent Relation** | Continued Interactions among a set of units; recorded as an annotation | 02 §2.4 |
| **Position** | The structural place an individual occupies: its levers and affordances across Domains | 01 §1.6 |
| **Realized State** | A measurement of a Domain's units as a collective; never a relatum | 01 §1.8 |
| **Registration** | An audience's uptake of a link's reading; depends on the audience's state | 08 §8.3 |
| **Retention** | The Constraint Principle applied standingly; fates Stillborn, Transient, Retained | 02 §2.3 |
| **Retraction Test** | A patch passes iff the System's original consequences survive outside the conflict | 06 V3 |
| **Seed** | The one-line core concept a System grows from; the interpretive anchor | 04 §4.2 |
| **Sparsity Register** | Open actual questions over decided modal space: unpopulated by design | 04 §4.3.5 |
| **Stance** | Authorial or Lens | 01 §1.5 |
| **Stipulated** | Genesis of a root: an axiom or a substrate declaration | 02 §2.6 |
| **Structural Profile** | Wholeness, Closure, Economy, Grounding, Self-regulation, Consistency | 04 |
| **Structuralist** | A structure-first worldbuilder; works by Licensing | SKILL.md |
| **Substrate** | What a System runs over: Base, Initial State, Boundary, Elections | 01 §1.4 |
| **System / system** | The tier (a nomic statement) / a unit of the ecosystem; write *unit* where ambiguous | 01 §1.6 |
| **System Coherence Criterion** | The System base is one System iff its co-reference graph is connected | 01 §1.8 |
| **Taxonomy Audit** | Partition, Product, Nesting and Naming Tests | 04 §4.4 |
| **Tendency Rule** | A distributional System: Norm, Deviation, Movers | 04 §4.3.3 |
| **Type L / S / P / Q** | Logical conflict / Scope collision / Plausibility strain / Magnitude conflict | 06 |
| **Witness Lore** | Derivations run only to exercise the System; discardable after logging | 06 F3 |
