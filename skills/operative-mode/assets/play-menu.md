# Play Menu

*Play Menu v1.1, for the Operative Mode Framework, Draft 0.4. Machine-readable copy: `play-menu.json`; random picks: `scripts/menu_draw.py`.*

The Play Menu gives a Player who is unsure what to play eighteen sets of options to pick from, and every pick maps onto a part of the Mode the Operator then builds.

## How to use the Menu

The Menu is offered when a Player does not know what to play, says "surprise me", or stalls at Declaration. Every pick is a User Declaration (marked **U**), and every category left unpicked stays the Operator's to elect.

**Offer it in small servings.** Eighteen lists at once is a wall. The Operator offers three categories first, and more only if the Player wants them:

1. **Story Type**, which chooses the Baseline Posture.
2. **One setting category** that suits it (Historical, Sci-Fi, Post-Apocalyptic, Dark World, Trope Fusion, Fantasy and Magic, or Environment).
3. **Tone and Atmosphere.**

After those, Story Hooks, Character Archetypes, Romantic Interest and Story Mechanics are offered as optional refinements. From each list the Operator shows five or six options suited to what is already picked, and names the rest as available.

**Picks combine.** A Player may take several options from one category (Horror and Mystery, or Transmigration and Entity of Power). Two picks from different setting categories produce a Trope Fusion.

**"Roll for me" is allowed.** The draw declares its source, as every draw does (§15.9): a Tool Draw where code runs, a User Roll, or Operator Judgment named as judgment.

**Some combinations fail Validation.** The Operator's own limits are a constraint on every Mode (§19.1), so a combination that would require excluded content is declined at construction, not three scenes in. For example, School combined with Romance runs only with adult characters (an academy, a university, a military college).

### What each category sets in the Mode

| Category | What it sets |
| --- | --- |
| Story Types | Baseline Posture; Interaction Basis; Narrative Organization |
| Character Archetypes | Stake Cards and Voice Cards of the Operator's Characters |
| Romantic Interest | Aims; an Operator Character's Want; Content Dials |
| Creatures and Beings | The world's population (Mode-specific material) |
| Historical, Sci-Fi, Post-Apocalyptic, Dark World, Trope Fusion, Fantasy and Magic | Setting and world rules; Causal Standard |
| Role and Profession | The Player's Character: Seat, governed objects, starting position |
| Social Structure | World rules; who holds power; what Operator Characters resist |
| Story Mechanics | Resolution Protocol; Clocks; Transparency; whether the Table Game Baseline fits |
| Story Hooks | Initial Context; the Player's Character's power source; a Signature Choice |
| Tone and Atmosphere | Tonal Range; Intensity Ceiling; Descriptive Density |
| Environment and Location | Setting; opening scene |
| Religions and Religious Themes | World rules; prophecy and scripture recorded as Claims (§16.8) |
| Politics and Ideology | Faction Stake Cards; world rules |
