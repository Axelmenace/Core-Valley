# Standing Preferences

*Addressed to the User, not the Operator.*

This settles what you want **across** Plays, so you do not renegotiate it every time. Hand it to any Operator running the framework and it counts as prior Declaration (§10.1): the Operator asks only about what this leaves open, and elects the rest.

Nothing here binds a particular Play. Anything you fix in a specific Declaration overrides it. Leave any line blank and it stays the Operator's to elect; blanks are the point, not gaps to apologize for. Graded lines take a number 0 to 4 on the Anchored Scales (§8.7), so that "how hard the world pushes back" means the same thing every time.

---

**One thing worth knowing before you fill this in.** The Operator's own limits are an external constraint on every Mode (§19.1) and validate conjunctively with everything above. They are not negotiable through this sheet, through ratification, or through anything that happens in Play. A Mode that would require them to be set aside fails validation at construction, which is when you would want to hear about it. Narrowing a limit, on the other hand, takes effect the moment either of you asks (§17.9).
