# Astrolabe theme

A look for the Claude desktop and mobile apps, taken from Astrolabe's own palette: brass and instrument teal on a night sky in dark mode, the same brass inked on vellum in light mode.

- **Colours**: every surface, text and accent colour in both modes, built with `makeColors`. Brass accent, rose for danger, verdigris for success, ember for warnings, twilight violet for literals.
- **Backdrop**: a star chart with two invented constellations and a brass astrolabe peeking in from the top-right corner. Its rete turns once every twelve minutes, the rule the other way more slowly still, and a few stars twinkle. With reduced motion on, it rests still.
- **Style**: serif headings, your messages in a brass-rimmed bubble, tool rows on a solid plate.
- **Sound** (off until you press the speaker in the title bar): a low observatory hum with far-off bells, and soft cues for send, tool, done, ask, error, compact and backdrop clicks.

## Install

At the prompt of a Claude Code session:

```
/plugin install astrolabe-theme --marketplace axelmenace/core-valley
```

Or from a shell:

```
claude plugin install astrolabe-theme --marketplace axelmenace/core-valley
```

Answer `y` to add the marketplace, then pick a scope. The look appears in the Claude desktop and mobile apps; a terminal draws no theme.

## Command

```
/astrolabe          the full look (default)
/astrolabe still    colours and style over a still wash, no motion or sound
/astrolabe plain    colours only
/astrolabe off      back to the app's own look
```

## Files

- `hooks/register.tsx`: the hooks module
- `hooks/palette.js`: the palette (edit the anchors and roles here)
- `hooks/scene.js`: the backdrop SVG, generated by `gen_scene.py` (`python3 gen_scene.py hooks/scene.js`)
- `hooks/make-colors.js`: the design system's colour builder, copied as is
- `tests/look.test.tsx`: `claude plugin test .`
